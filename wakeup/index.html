起床了 · 隐私政策

生效日期：2026-10-25

适用于 iOS 应用「起床了」（Bundle ID：com.wakeup.rise）及随附的实时活动扩展

「起床了」（下称「本应用」）重视您的隐私。本政策说明我们如何处理信息。若您不同意，请停止使用本应用。

1. 开发者与联系方式

开发者：起床了

联系邮箱：zybshahe@163.com

2. 产品范围

  • 主应用（iPhone / iPad）
  • 实时活动（Live Activity，例如喝水、久坐等状态）

当前版本不上架主屏幕 / 锁屏小组件。不包含 Apple Watch 应用。

3. 我们处理哪些信息

本应用不要求注册账号，也不运营登录用户系统。下列信息默认保存在您的设备本地（含 App Group，供实时活动等本机扩展读取）。我们不运营自有服务器来托管这些内容。

  • 闹铃与提醒：名称、时间、重复规则、分组、节假日相关偏好、任务挂载等。
  • 早起 / 喝水 / 任务记录：完成时间、次数、可选的本机训练录像文件名等统计与记录。
  • 自定义铃声：您主动录音时使用麦克风；音频文件保存在本机，可用于闹铃播放。
  • 自定义头像 / 选图：若您通过系统照片选择器选图，本应用仅获得所选图片并本地保存，不申请访问全部相册。
  • 任务相关传感器与媒体（仅在您使用对应任务时）：
    • 相机：姿态识别、拍照核验；若您开启训练录像，视频保存在本机，便于回看、分享或删除；
    • 麦克风 / 语音识别：学动物叫、朗读核验等，在设备上分析；
    • 运动与体能：计步、摇晃手机等任务。
  • 密码本（可选）：您主动保存的账号条目保存在本机；可选用 Face ID / 系统生物识别解锁查看。卸载应用后本地数据通常随之删除。
  • 系统权限：AlarmKit 闹铃、通知、麦克风、相机、语音识别、运动与体能、Face ID 等由 iOS 管理，可在系统设置中更改。

4. 关于网络

  • 不会向开发者自有服务器或第三方业务接口拉取业务数据（节假日等使用 App 内打包的本地数据，可离线使用）。
  • 设置中的隐私政策、去评分等链接，仅在您主动点击后由系统浏览器打开，不是应用后台静默请求。
  • 您主动分享口令、图片或录像时，走系统分享面板，由您选择的目标 App 按其规则处理。

5. 我们如何使用信息

  • 提供系统级闹铃、任务停铃、日历、早起 / 喝水记录与实时活动；
  • 播放您配置的铃声或自定义录音；
  • 在本机完成任务识别、可选录像与统计；
  • 在您选用时提供密码本本地保管。

6. 信息共享

我们不会出售您的个人信息。除法律要求或保护安全所必需外，我们不会把您的闹铃内容、录音、图片、录像或密码本主动提供给第三方。

本应用当前未集成第三方广告 SDK，也未使用 ATT 做跨 App 广告追踪。

7. 存储与保留

核心内容保存在您的设备上。卸载应用或清除应用数据后，本地数据通常会被删除（以 iOS 行为为准）。您分享出去的内容由接收方与对应平台处理，不在本应用控制范围内。

8. 儿童隐私

本应用面向一般用户，不专门面向儿童收集个人信息。监护人如有疑问，请通过上方邮箱联系我们。

9. 您的选择

  • 在系统设置中关闭相关权限（对应功能可能不可用）；
  • 不使用录音、选图、任务录像、密码本等可选能力；
  • 卸载本应用以停止使用。

10. 政策更新

我们可能更新本政策，并在本页修订生效日期。重大变更时，会尽量通过 App Store 产品页或其他合理方式提示。
