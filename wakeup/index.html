起床了 · 隐私政策

生效日期：2026-10-25

适用于 iOS / watchOS 应用「起床了」（Bundle ID：com.wakeup.rise）及随附的实时活动与 Apple Watch 配套应用

「起床了」（下称「本应用」）重视您的隐私。本政策说明我们如何处理信息。若您不同意，请停止使用本应用。

1. 开发者与联系方式

开发者：起床了

联系邮箱：zybshahe@163.com

2. 产品范围

  • 主应用（iPhone / iPad）
  • 实时活动（Live Activity：闹铃倒计时、喝水等状态）
  • Apple Watch 配套应用（闹铃快照、喝水等本机同步显示与简易操作）

当前版本不上架主屏幕 / 锁屏小组件。

3. 我们处理哪些信息

本应用不要求注册账号，也不运营登录用户系统。下列信息默认保存在您的设备本地（含 App Group，以及与配对 iPhone 之间的 WatchConnectivity 本机同步，供实时活动 / Apple Watch 配套功能读取）。我们不运营自有服务器来托管这些内容。

  • 闹铃与提醒：名称、时间、重复规则、分组、节假日相关偏好、任务挂载、所选内置铃声等。
  • 早起 / 喝水 / 任务记录：完成时间、次数、可选的本机训练录像文件名等统计与记录。
  • 内置铃声：闹铃可选的经典铃声音频为 App 内打包资源，不采集您的声音内容。
  • 任务相关传感器与媒体（仅在您使用对应任务时）：
    • 相机：姿态识别、拍照核验；若您开启训练录像，视频保存在本机，便于回看、分享或删除；
    • 麦克风 / 语音识别：朗读核验等任务在设备上分析，不上传；
    • 运动与体能：计步、摇晃手机等任务。
  • 闹铃口令与剪贴板：您主动复制 / 分享口令时写入系统剪贴板；仅在您确认粘贴导入时读取剪贴板中的口令文本，用于生成本机闹铃。
  • 密码本（可选）：您主动保存的账号条目经加密后保存在本机钥匙串（Keychain）；可选用系统身份验证（Face ID / Touch ID / 设备密码）解锁查看。卸载应用后钥匙串中的条目通常仍会保留；清除钥匙串、抹除设备或恢复新机后才会消失。
  • 系统权限：AlarmKit 闹铃、通知（含喝水及未完成任务追催）、麦克风、相机、语音识别、运动与体能、系统身份验证等由 iOS 管理，可在系统设置中更改。

4. 关于网络

  • 本应用不具备业务联网能力，不向开发者自有服务器或第三方业务接口收发数据；节假日等均使用 App 内打包的本地数据，可完全离线使用。
  • 设置中的隐私政策、去评分等，仅在您主动点击后交给系统浏览器打开（由系统处理，非本应用内置联网功能）。
  • 您主动分享口令、图片或录像时，走系统分享面板，由您选择的目标 App 按其规则处理。

5. 我们如何使用信息

  • 提供系统级闹铃、任务停铃、日历、早起 / 喝水记录、实时活动与 Apple Watch 配套显示；
  • 按您的选择播放内置铃声；
  • 在本机完成任务识别、可选录像与统计；
  • 在您选用时提供密码本本地保管。

6. 信息共享

闹铃内容、任务录像、口令与密码本等均保存在您的设备本地，本应用不上传至开发者服务器，开发者侧不持有这些内容，因此也不存在向第三方提供上述内容的情况。您主动通过系统分享（如复制口令、分享长图或录像）发出的内容，由您自行选择接收方，不属于开发者向第三方披露。

本应用当前未集成第三方广告 SDK，也未使用 ATT 做跨 App 广告追踪。

7. 存储与保留

核心内容保存在您的设备上。卸载应用或清除应用数据后，本地数据通常会被删除（以 iOS / watchOS 行为为准）；密码本钥匙串条目见上文说明。您分享出去的内容由接收方与对应平台处理，不在本应用控制范围内。

8. 儿童隐私

本应用面向一般用户，不专门面向儿童收集个人信息。监护人如有疑问，请通过上方邮箱联系我们。

9. 您的选择

  • 在系统设置中关闭相关权限（对应功能可能不可用）；
  • 不使用任务录像、朗读类任务、密码本等可选能力；
  • 卸载本应用以停止使用。

10. 政策更新

我们可能更新本政策，并在本页修订生效日期。重大变更时，会尽量通过 App Store 产品页或其他合理方式提示。
